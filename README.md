Lantern Row is a rain-soaked neon night-market tactical FPS built with three.js for make.fun's [Make the best three.js tactical FPS](https://make.fun/bounty/threejs-fps-02) bounty ($1,000 in USDC). Vanguard (cyan) vs Jackals (orange) across Sites A/B: plant the Spark, defend or defuse, with a power-round railgun every third round, 7 bots, 5 weapons, and frag, smoke, and flash utility.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
